Chapitre 1

Présentation de la plateforme

GuinéeMarché est une place de marché en ligne guinéenne permettant à des particuliers et commerçants de vendre et acheter des biens de manière sécurisée, avec un système de paiement escrow, une livraison intégrée et des virements automatiques.

🛍️ Acheteur 🏪 Vendeur 🚗 Livreur 🛡️ Administrateur
ProfilCe qu'il peut faire
AcheteurParcourir les annonces, passer des commandes, payer, confirmer la réception
VendeurPublier des annonces, confirmer les commandes, recevoir des virements automatiques
LivreurAccepter des missions de livraison, suivre les commandes GPS, recevoir un salaire hebdomadaire automatique
AdministrateurGérer tous les utilisateurs, résoudre les litiges, piloter la comptabilité
🌐 Accès à la plateforme

Web : guimatrix.com (navigateur PC ou mobile)

Application mobile : Android — disponible sur demande (APK)

Administration : guimatrix.com/admin (comptes admin uniquement)

Chapitre 2

Inscription et connexion

2.1 Créer un compte

1
Ouvrir la page d'inscription Sur le web : cliquer sur « S'inscrire » depuis la page d'accueil. Sur l'appli mobile : appuyer sur « Créer un compte » dans l'écran de connexion.
2
Remplir le formulaire Nom complet · Numéro de téléphone guinéen (ex : 620 000 000) · Mot de passe (min. 8 caractères) · Confirmation du mot de passe.
3
Code de parrainage (facultatif) Si un ami vous a donné son code de parrainage, le saisir ici pour bénéficier d'avantages mutuels.
4
Déclarer la possession légale des biens Cocher la case d'attestation anti-recel. Cette déclaration est obligatoire.
5
Valider et recevoir le code OTP Un SMS est envoyé sur le numéro fourni. Saisir ce code dans les 10 minutes pour activer le compte.
⚠️ Un seul compte par numéro de téléphone. Si le numéro est déjà enregistré, utiliser « Mot de passe oublié » pour récupérer l'accès.

2.2 Vérification OTP

Après l'inscription, un code à 6 chiffres est envoyé par SMS. Saisir ce code dans le champ prévu. Si le code n'arrive pas après 60 secondes, utiliser le bouton « Renvoyer le code ».

⏱️ Validité du code OTP
Le code expire après 10 minutes. Au-delà, demander un nouveau code. Le système limite les tentatives pour éviter les abus.

2.3 Connexion et mot de passe oublié

Pour se connecter : saisir le numéro de téléphone et le mot de passe, puis appuyer sur « Se connecter ».

Mot de passe oublié :

1
Cliquer sur « Mot de passe oublié » sous le formulaire de connexion.
2
Saisir le numéro de téléphone enregistré. Un SMS avec un code de réinitialisation est envoyé.
3
Saisir le code, puis choisir un nouveau mot de passe.
Chapitre 3

Profil utilisateur

Accessible depuis le menu principal (icône profil), la page profil regroupe toutes les informations personnelles et les paramètres du compte.

3.1 Modifier le profil

1
Cliquer sur « ✏️ Modifier » dans la carte profil.
2
Mettre à jour l'adresse e-mail, la ville (liste déroulante de toutes les villes guinéennes), et le quartier (liste mise à jour automatiquement selon la ville choisie).
3
Cliquer sur « Enregistrer ». Le profil est mis à jour immédiatement.

3.2 Informations de paiement (Vendeurs)

Pour recevoir des virements ChaChaP, le vendeur doit renseigner son numéro de téléphone ChaChaP dans la section « 💰 Mes gains » ou « Infos de paiement ».

ℹ️ Opérateurs acceptés pour le payout
Orange Money · MTN MoMo · Skrill · PayPal · Virement bancaire (BNI, Ecobank, Bicigui…) · Wave

3.3 Abonnement et quota d'annonces

PlanAnnonces gratuitesFonctionnalités
GratuitQuota défini par l'adminPublication standard
ProIllimitéMise en avant, statistiques avancées

3.4 Mes annonces

La section « Mes annonces » liste toutes les annonces publiées avec leur statut (Active, Expirée, Brouillon). Les annonces expirées sont automatiquement désactivées.

3.5 Historique et statistiques

Le profil affiche des graphiques d'activité (commandes, annonces) pour les 6 derniers mois, ainsi que le nombre d'avis reçus et la note moyenne.

Chapitre 4

Achat — Recherche et commande

🛍️ Acheteur

4.1 Rechercher une annonce

Depuis la page d'accueil, utiliser la barre de recherche ou les filtres :

  • Catégorie (Électronique, Vêtements, Véhicules…)
  • Ville et quartier
  • Fourchette de prix
  • État de l'article (Neuf, Bon état, Usagé)

Les annonces récentes apparaissent en tête. Les articles consultés récemment sont visibles dans « Consultés récemment ».

4.2 Passer une commande

1
Ouvrir la page de l'annonce et vérifier les détails (prix, description, photos, ville du vendeur).
2
Cliquer sur « 🛒 Acheter » (web) ou appuyer sur le bouton d'achat (mobile). Une fenêtre modale s'ouvre.
3
Choisir le mode de livraison (voir section 4.3), renseigner l'adresse ou le lieu, puis choisir le mode de paiement.
4
Si prix négociable : saisir le prix proposé. Le vendeur pourra accepter ou refuser.
5
Confirmer la commande. Un code de vérification unique est généré et affiché — le conserver pour la livraison.
💡 La commande apparaît immédiatement dans « Mes commandes » avec le statut En attente.

4.3 Modes de livraison

ModeDescriptionChamp requis
🤝 Main propre Rencontre physique avec le vendeur dans un lieu convenu Lieu de rencontre (ex : Marché Madina)
🏪 Point de retrait Retrait dans un point relais du réseau GuinéeMarché Point de retrait souhaité
🚗 Livraison domicile Un livreur apporte l'article à votre adresse. Des frais de livraison peuvent s'appliquer. Adresse complète (quartier, rue, repère)
🚗 Livraison à domicile — Code de vérification
Un code à 6 chiffres est généré à la commande. Ce code est remis au livreur lors de la livraison pour confirmer la remise en main propre. Ne pas le communiquer avant d'avoir reçu l'article.

4.4 Confirmer la réception

Après la livraison, l'acheteur doit confirmer la réception dans un délai de 24 heures (72 heures pour les commandes importantes).

1
Ouvrir « Mes commandes » et localiser la commande au statut Confirmée.
2
Cliquer sur « ✅ Confirmer réception ».
3
Les fonds en escrow sont automatiquement virés au vendeur. La commande passe au statut Terminée.
⚠️ Si vous ne confirmez pas dans le délai imparti, les fonds sont automatiquement libérés et virés au vendeur. En cas de problème, ouvrir un litige avant expiration du délai.
Chapitre 5

Paiement

5.1 ChaChaP — Mobile Money

ChaChaP est le système de paiement principal de GuinéeMarché. Il prend en charge les principaux opérateurs guinéens.

1
Depuis la commande, cliquer sur « 💳 Payer ».
2
Choisir l'opérateur : Orange Money · MTN MoMo · Skrill · PayPal · Wave.
3
Saisir le numéro de téléphone lié au portefeuille mobile.
4
Confirmer le paiement. Une notification de confirmation est envoyée par SMS et dans l'application.
💡 Les fonds sont placés en escrow (séquestre sécurisé) jusqu'à la confirmation de réception par l'acheteur.

5.2 En espèces (Cash)

Pour les commandes avec remise en main propre ou chez un livreur, le paiement en espèces est possible.

💵 Processus paiement cash
Acheteur
Sélectionne « En espèces » lors de la commande. La commande reste en attente.
Vendeur
Reçoit la commande, organise la rencontre et collecte l'argent en main propre.
Vendeur
Appuie sur « ✅ Confirmer » dans « Mes ventes » pour indiquer que le paiement a été reçu. La commande passe au statut Confirmée.
Acheteur
Confirme la réception de l'article pour finaliser la transaction.

5.3 Statuts de paiement

StatutSignification
En attentePaiement non encore effectué
En coursPaiement en cours de traitement
RéussiPaiement confirmé — fonds en escrow
ÉchouéPaiement rejeté (solde insuffisant, numéro invalide…)
RembourséFonds restitués à l'acheteur (litige résolu en sa faveur)
Chapitre 6

Vente — Publier et gérer des annonces

🏪 Vendeur

6.1 Créer une annonce

1
Accéder à « Publier » depuis le menu (bouton + ou icône crayon).
2
Renseigner les informations : Titre · Catégorie · Description détaillée · Photos (jusqu'à plusieurs images) · Prix en GNF · Type de prix (Fixe / Négociable / Gratuit) · État (Neuf / Bon état / Usagé).
3
Sélectionner la ville et le quartier de retrait ou de livraison.
4
Publier. L'annonce est visible immédiatement par tous les acheteurs.
⚠️ Quota d'annonces
Le compte gratuit a un quota d'annonces actives simultanées. Au-delà, passer au Plan Pro ou supprimer des annonces existantes.

6.2 Confirmer une commande reçue

Quand un acheteur passe une commande, le vendeur reçoit une notification et doit confirmer la commande pour l'accepter.

1
Ouvrir « Mes ventes » (web) ou onglet « 🏪 Ventes » dans « Mes commandes » (mobile).
2
Localiser la commande au statut En attente.
3
Cliquer sur « ✅ Confirmer la commande » (ou « ✅ Confirmer » pour les paiements en espèces après réception de l'argent).
💡 Si le vendeur n'accepte pas la commande, l'acheteur peut l'annuler. Il est recommandé de confirmer rapidement.

6.3 Gains et virements automatiques

GuinéeMarché applique une commission de 4 % sur chaque vente complétée. Le reste est versé automatiquement sur le compte ChaChaP du vendeur.

💸 Processus de virement automatique
Acheteur confirme réception
Les fonds sont libérés de l'escrow.
Immédiat (automatique)
96 % du montant est viré via ChaChaP B2C sur le numéro renseigné par le vendeur.
Notification
Le vendeur reçoit une notification de confirmation du virement.

Si le numéro de paiement n'est pas renseigné

Le virement reste en attente (Pending) et l'administrateur est notifié. Le vendeur doit renseigner son numéro ChaChaP dans son profil pour recevoir ses fonds.

Consulter ses gains

Dans le profil → « 💰 Mes gains » : tableau de bord avec les gains complétés, en attente et échoués, ainsi que l'historique de chaque virement.

Chapitre 7

Livraison

🚗 Livreur

7.1 S'inscrire comme livreur

Lors de l'inscription ou depuis les paramètres du profil, sélectionner le rôle « Livreur ». L'administrateur valide les livreurs avant activation.

7.2 Tableau de bord livreur

L'écran « Mes livraisons » (mobile) ou le tableau de bord livreur (web) affiche :

  • Les missions en attente d'acceptation
  • Les missions en cours avec le suivi GPS
  • L'historique des livraisons complétées
  • Le toggle de disponibilité (disponible / indisponible)

Workflow de livraison

1
Recevoir une mission : notification push dès qu'une commande à livrer est disponible dans sa zone.
2
Accepter la mission en appuyant sur « Accepter » — la mission est alors réservée pour ce livreur.
3
Aller chercher l'article chez le vendeur. Appuyer sur « Démarrer la livraison » pour activer le suivi GPS.
4
Livrer à l'acheteur. Demander le code de vérification à 6 chiffres et le saisir dans l'application pour confirmer la remise.
5
La livraison est marquée comme Terminée et les gains sont enregistrés.
💡 L'acheteur peut suivre la position du livreur en temps réel sur la carte depuis « Mes commandes ».

7.3 Rémunération et salaires automatiques

💰 Salaire hebdomadaire automatique

Chaque lundi matin, le système calcule automatiquement le salaire de la semaine écoulée pour chaque livreur :

  • Total des gains bruts (commissions par livraison)
  • Déduction des éventuelles amendes (retards, annulations)
  • Virement automatique via ChaChaP B2C sur le numéro renseigné

Renseigner son numéro de paiement

Dans le profil → « Infos de paiement livreur » : saisir le numéro de téléphone ChaChaP pour recevoir le salaire automatiquement. Sans ce numéro, le salaire reste en attente et l'admin est notifié.

Amendes

Chapitre 8

Escrow — Protection des fonds

Le système d'escrow (séquestre) est le mécanisme central de sécurité de GuinéeMarché. Il garantit que l'acheteur est livré avant que le vendeur soit payé.

🔒 Comment fonctionne l'escrow
Paiement
L'acheteur paie. Les fonds sont bloqués en escrow (ni chez l'acheteur, ni chez le vendeur).
Livraison
Le vendeur expédie ou remet l'article. Le livreur effectue la livraison.
Confirmation de réception
L'acheteur confirme avoir reçu l'article en bon état.
Libération automatique
Les fonds sont virés au vendeur (96 %) et la commission de 4 % revient à GuinéeMarché.
Expiration (24h / 72h)
Si l'acheteur ne confirme pas dans le délai, les fonds sont automatiquement libérés et virés au vendeur. Ouvrir un litige AVANT expiration pour bloquer ce processus.
⛔ Les fonds en escrow ne peuvent pas être retirés directement. Toute fraude (faux paiement, fausse confirmation) est détectée et peut entraîner la suspension du compte.
Chapitre 9

Litiges

9.1 Quand ouvrir un litige

Un litige doit être ouvert si :

  • L'article reçu ne correspond pas à la description
  • L'article est endommagé ou incomplet
  • Le vendeur ne répond plus et l'article n'est pas arrivé
  • Tout autre désaccord commercial
⚠️ Ouvrir le litige avant de confirmer la réception et avant l'expiration du délai d'escrow. Passé ce délai, les fonds sont libérés et le litige ne peut plus bloquer le paiement.

9.2 Comment ouvrir un litige

1
Ouvrir « Mes commandes » et localiser la commande concernée.
2
Appuyer sur « ⚠️ Litige » (disponible au statut En attente ou Confirmée).
3
Confirmer l'ouverture du litige. Les fonds sont immédiatement bloqués en attendant la décision de l'administrateur.

9.3 Résolution du litige

Décision adminConséquence
En faveur de l'acheteurRemboursement complet à l'acheteur
En faveur du vendeurFonds virés au vendeur (96 % habituel)
PartageFonds répartis selon la décision de l'admin
💡 L'équipe GuinéeMarché peut vous contacter pour recueillir des preuves (photos, captures d'écran, messages). Conservez toutes les preuves pertinentes.

Chapitre 12

Administration

🛡️ Administrateur

Le panel d'administration est accessible à guimatrix.com/admin (comptes admin et super admin uniquement). Il est divisé en plusieurs onglets.

12.1 Tableau de bord principal

Affiche les indicateurs clés en temps réel :

  • Utilisateurs actifs (total, vendeurs, livreurs, acheteurs)
  • Commandes du jour / semaine / mois
  • Chiffre d'affaires et commissions
  • Litiges en cours
  • Virements en attente

12.2 Gestion des utilisateurs

L'onglet « Utilisateurs » liste tous les comptes avec leurs informations, statuts et rôles. L'admin peut :

  • Suspendre ou réactiver un compte
  • Changer le rôle (acheteur → vendeur, livreur…)
  • Valider les livreurs en attente de validation
  • Voir le profil complet et l'historique d'activité

12.3 Virements et comptabilité

L'onglet « Comptabilité » donne accès à :

Virements vendeurs (SellerPayouts)

ActionDescription
Filtrer par statutPending / Processing / Completed / Failed / All
🚀 VirerDéclencher manuellement un virement ChaChaP pour un payout bloqué
✓ ManuelMarquer un payout comme payé manuellement (ex : virement bancaire hors système)
Export CSVTélécharger l'historique complet des virements

Salaires livreurs (Weekly Payouts)

ActionDescription
Vue par livreurDétail des missions, amendes et net à payer

⚙️ Automatisation complète

En fonctionnement normal, aucune intervention manuelle n'est requise :

  • Virements vendeurs → automatiques à la confirmation de réception
  • Salaires livreurs → automatiques chaque lundi matin
  • Expiration escrow → automatique après 24h / 72h
  • Expiration annonces → automatique à minuit chaque jour

L'admin n'intervient que pour les litiges et les cas d'échec de virement.

12.4 Gestion des litiges

L'onglet « Litiges » liste tous les litiges ouverts.

1
Sélectionner le litige à traiter. Consulter les détails : montant, acheteur, vendeur, messages échangés.
2
Contacter les deux parties si nécessaire pour recueillir des preuves supplémentaires.
3
Choisir la décision : Rembourser l'acheteur (fonds retournés manuellement) ou Libérer vers le vendeur (virement automatique).
⚠️ Remboursement acheteur
En cas de remboursement décidé en faveur de l'acheteur, une notification est envoyée à l'équipe comptable avec les coordonnées de l'acheteur pour procéder au remboursement manuel via ChaChaP.

Autres fonctions admin

  • Annonces : supprimer ou désactiver des annonces non conformes
  • Catégories : gérer les catégories et sous-catégories d'annonces
  • Amendes livreurs : créer et suivre les amendes
  • Retours : approuver ou rejeter les demandes de retour produit
  • Notifications : envoyer des messages groupés aux utilisateurs
  • Export comptabilité : télécharger l'ensemble des données en CSV

Chapitre 14

Questions fréquentes

💬 Général

Q : Pourquoi mon annonce n'apparaît-elle pas ?

Vérifiez que votre quota d'annonces n'est pas atteint et que l'annonce n'a pas expiré. Les annonces sont actives par défaut après publication.

Q : Comment contacter un vendeur ?

Depuis la page de l'annonce, utiliser le bouton « 💬 Message » pour envoyer un message direct.

Q : Puis-je modifier une annonce après publication ?

Oui, depuis « Mes annonces » → modifier l'annonce. Les prix et descriptions peuvent être mis à jour à tout moment.

💳 Paiement

Q : Mon paiement a échoué. Que faire ?

Vérifier le solde du compte mobile money, que le numéro saisi est correct, et réessayer. Si le problème persiste, contacter le support.

Q : En combien de temps est viré mon argent (vendeur) ?

Le virement est immédiat et automatique dès que l'acheteur confirme la réception. En cas de non-confirmation, les fonds sont automatiquement libérés après 24 ou 72 heures.

Q : Je n'ai pas reçu mon virement. Que faire ?

Vérifier que le numéro ChaChaP est bien renseigné dans « Infos de paiement ». Si le virement est en statut « Échoué », contacter l'administrateur depuis le menu profil.

📦 Livraison

Q : Comment suivre ma livraison ?

Dans « Mes commandes » → sélectionner la commande → le suivi GPS du livreur est visible en temps réel sur la carte (si mode livraison domicile).

Q : Je n'ai pas reçu mon code de vérification.

Le code est affiché dans les détails de la commande dans « Mes commandes ». Il est aussi envoyé par notification push.

Q : Mon livreur ne répond plus.

Ouvrir un litige depuis la commande. L'administrateur interviendra pour résoudre la situation.

⚖️ Litiges

Q : J'ai confirmé la réception par erreur. Puis-je récupérer mon argent ?

Une fois la réception confirmée, les fonds sont virés au vendeur et la transaction est finalisée. Il n'est plus possible d'ouvrir un litige. Contacter directement le vendeur et l'équipe support en dernier recours.

Q : Le litige est ouvert depuis plusieurs jours, que se passe-t-il ?

L'équipe traite les litiges dans un délai de 2 à 5 jours ouvrés. Vous serez notifié dès qu'une décision est prise.

🚗 Livreurs

Q : Quand suis-je payé ?

Chaque lundi matin, le salaire de la semaine écoulée est calculé et viré automatiquement.

Q : Une amende a été déduite de mon salaire sans raison. Que faire ?

Contacter l'administrateur depuis le profil pour contester l'amende. L'admin dispose d'un accès à l'historique complet.

Q : Comment modifier mon numéro de paiement ?

Profil → « Infos de paiement livreur » → modifier le numéro et enregistrer. Le changement prend effet au prochain calcul de salaire.
