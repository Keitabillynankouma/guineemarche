1

Devenir livreur

  1. 1
    Rendez-vous sur guimatrix.com et créez un compte en sélectionnant le rôle « Livreur ».
  2. 2
    Complétez votre profil avec vos informations : nom, quartier d'opération, moyen de transport.
  3. 3
    Soumettez votre candidature. L'équipe GuinéeMarché valide votre profil sous 24-48h.
  4. 4
    Une fois approuvé, vous recevez une notification et vous pouvez commencer à accepter des missions.
✅ Il n'y a pas de quota minimum. Vous travaillez à votre rythme — acceptez les missions quand vous êtes disponible.
💡 Renseignez un numéro Mobile Money dans votre profil dès l'inscription pour recevoir vos paiements sans délai.

3

Accepter une mission

  1. 1
    Consultez la section « Missions disponibles ». Chaque mission indique la zone de retrait, la zone de livraison et les frais.
  2. 2
    Vérifiez que la mission est dans votre zone d'opération et que vous êtes disponible.
  3. 3
    Cliquez « Accepter ». La mission vous est maintenant assignée.
  4. 4
    Vous recevez les coordonnées du vendeur (nom, quartier, numéro de contact).
⚠️ Une fois une mission acceptée, engagez-vous à la mener jusqu'au bout. Les abandons répétés impactent votre note.
4

Récupérer le colis chez le vendeur

C'est l'étape de pickup. Vous allez chercher l'article chez le vendeur pour le livrer à l'acheteur.

  1. 1
    Contactez le vendeur via l'application (numéro affiché dans la mission) pour confirmer votre heure de passage.
  2. 2
    Rendez-vous à l'adresse indiquée.
  3. 3
    Présentez au vendeur votre code pickup depuis l'application (section détail de la mission).
  4. 4
    Le vendeur vérifie le code et vous remet le colis si les codes correspondent.
  5. 5
    Cliquez « Colis récupéré » dans l'application. Le statut passe à En transit.
✅ Le code pickup protège les deux parties : vous êtes certifié comme livreur légitime, le vendeur est sûr de remettre à la bonne personne.
💡 Inspectez visuellement le colis avant de le prendre. Si le colis est endommagé ou non conforme à la description, signalez-le immédiatement via le support.
5

Livrer à l'acheteur

  1. 1
    Consultez l'adresse de livraison dans le détail de la mission.
  2. 2
    Contactez l'acheteur pour confirmer qu'il est disponible à la réception.
  3. 3
    Rendez-vous à l'adresse de l'acheteur.
  4. 4
    Remettez le colis en main propre.
  5. 5
    Demandez à l'acheteur son code de vérification pour confirmer la livraison (voir section 6).
⚠️ Ne laissez jamais le colis sans présence de l'acheteur sans son accord explicite. En cas d'absence, recontactez-le et signalez la situation dans l'application.
6

Le code de vérification (confirmation de livraison)

Le code de vérification est le moyen officiel de confirmer que la livraison a bien eu lieu. C'est l'acheteur qui le détient — pas le livreur.

Comment ça marche ?

  1. 1
    L'acheteur reçoit son code de vérification à 6 chiffres dans l'application au moment de la commande.
  2. 2
    Lors de la livraison, demandez ce code à l'acheteur et saisissez-le dans l'application.
  3. 3
    Si le code est correct → la livraison est confirmée → la mission se clôture → les fonds sont libérés au vendeur.
🔴 IMPORTANT : Vous ne voyez jamais ce code dans votre application — c'est délibéré. Ne demandez pas à l'acheteur de vous envoyer le code avant la livraison. Le code ne se partage qu'en face à face au moment de la remise du colis.
⚠️ Si l'acheteur ne retrouve pas son code, demandez-lui de vérifier dans la section « Mes commandes » de l'application.

Vos revenus et paiements

9

Gérer les incidents

SituationQue faire
Le vendeur est absent au pickupAppelez-le. S'il ne répond pas sous 30 min, signalez dans l'application → "Vendeur injoignable" et contactez le support.
L'acheteur est absent à la livraisonAppelez-le. S'il ne répond pas, prenez une photo devant l'adresse, signalez dans l'app. Discutez d'un second passage avec l'acheteur.
Le colis est endommagéPhotographiez avant de le prendre. Signalez immédiatement via le support. Ne prenez pas un colis visiblement endommagé sans signalement.
L'acheteur refuse le colisNe forçez pas. Signalez le refus dans l'application. Le support tranche entre vendeur et acheteur.
Vous êtes en retardPrévenez l'acheteur via l'application dès que vous savez. La communication réduit les mauvaises notes.
💡 Le support GuinéeMarché est disponible dans l'application → Menu → 💬 Support. Décrivez l'incident avec précision.
10

Votre profil et réputation

Votre note est un élément clé : les vendeurs et acheteurs peuvent voir votre score avant de vous faire confiance.

IndicateurComment l'améliorer
⭐ Note moyenneSoyez ponctuel, soigneux et communiquant. Les avis positifs montent votre note.
📦 Livraisons réussiesChaque livraison confirmée s'ajoute à votre compteur.
🕐 Taux de ponctualitéRespectez les créneaux convenus. Prévenez en cas de retard.
🚫 Taux d'abandonAcceptez uniquement ce que vous pouvez accomplir. Un abandon non justifié pénalise votre score.
11

Questions fréquentes

QuestionRéponse
Puis-je refuser une mission après l'avoir acceptée ?Oui, en cas d'urgence ou d'empêchement réel. Signalez-le dans l'application le plus tôt possible pour minimiser l'impact sur votre note.
Que se passe-t-il si l'acheteur perd son code de vérification ?L'acheteur peut retrouver son code dans "Mes commandes". En dernier recours, le support peut valider la livraison manuellement.
Je n'ai pas reçu mon paiement hebdomadaireVérifiez que votre numéro Mobile Money est bien configuré. Si oui, contactez le support avec la semaine concernée.
Un acheteur m'a donné un mauvais avis injusteContactez le support avec les détails de la mission. L'équipe peut examiner et rectifier en cas d'erreur.
Puis-je opérer dans plusieurs villes ?Oui. Mettez à jour votre zone d'opération dans votre profil.
