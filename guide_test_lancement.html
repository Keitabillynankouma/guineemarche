JOUR 1 — Flux Principaux

BLOC 1 — Inscription & Authentification

ℹ️ Tester avec 3 comptes différents : un acheteur, un vendeur, un livreur. Utiliser de vrais numéros de téléphone guinéens.
N°ScénarioÉtapesRésultat attenduOK?
T01Inscription acheteur1. Ouvrir guimatrix.com 2. Cliquer "S'inscrire" 3. Remplir : nom, téléphone, mot de passe 4. Choisir rôle "Acheteur" 5. ValiderSMS OTP reçu en < 60 sec. Compte créé et redirigé vers accueil.
T02Vérification OTP1. Saisir le code OTP reçu 2. SoumettreCompte vérifié. Badge vert visible dans profil.
T03OTP expiré (>10 min)1. Attendre 11 minutes sans saisir le code 2. Saisir l'ancien codeMessage d'erreur "Code expiré". Proposition de renvoyer.
T04OTP faux (3 tentatives)1. Saisir un mauvais code 3 fois de suiteBlocage temporaire. Message d'erreur clair.
T05Inscription vendeur1. Répéter T01 avec rôle "Vendeur" 2. Ajouter nom de boutiqueCompte vendeur créé avec boutique associée.
T06Inscription livreur1. Répéter T01 avec rôle "Livreur" 2. Activer disponibilitéCompte livreur actif et disponible.
T07Connexion valide1. Se déconnecter 2. Se reconnecter avec téléphone + mot de passeConnexion réussie. Tokens JWT rafraîchis.
T08Mauvais mdp (10x)1. Tenter 10 connexions avec un mauvais mot de passeAprès 10 tentatives : throttle activé (erreur 429).
T09Réinitialisation mdp1. Cliquer "Mot de passe oublié" 2. Saisir numéro de téléphone 3. Recevoir OTP de réinitialisation 4. Définir nouveau mot de passeMot de passe changé. Ancienne session invalidée.
T10Code parrainage1. Copier le code parrainage du compte acheteur 2. Créer un nouveau compte avec ce codeNouveau compte lié au parrain. Visible dans le profil.
